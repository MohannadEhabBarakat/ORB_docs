OpenRadBench was built using several incredible open-source tools and platforms. We would like to acknowledge and thank the creators and maintainers of the following technologies:

## Core Technologies

- **[NiiVue](https://github.com/niivue/niivue)**: A highly performant WebGL 2.0 medical image viewer used for rendering imaging data seamlessly in the browser.
- **[MongoDB](https://www.mongodb.com/)**: Our NoSQL database of choice, providing flexible and scalable document storage for annotations and study configurations.
- **[Vercel](https://vercel.com/)**: The hosting and deployment platform powering our frontend applications with edge network performance.
- **[FastAPI](https://fastapi.tiangolo.com/)**: A modern, fast (high-performance) web framework used for building our backend APIs in Python.
