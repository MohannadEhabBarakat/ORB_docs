This is a light, stand-alone Gradio app. It implements a combination of features:
- Generate ground truth from a group of annotations (i.e., Humans)
- Generates 2 ground truths with voting and STAPLE
- Compare every annotation with every ground truth.
- Create a 4D scatter plot using x, y, size, and colour dimensions.
