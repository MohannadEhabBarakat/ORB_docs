Welcome to the OpenRadBench installation guide! We offer an automated setup for a quick start, as well as manual instructions for more control.

## Auto Installation (Recommended)

For most users and development purposes, we recommend using the automated installation script. This script uses `tmux` to automatically clone the repositories, install dependencies, and start all necessary services seamlessly (including the backend, annotation tool, admin dashboard, and analysis backend).

To use the automated setup, simply execute the provided script in this directory:

```bash
./start_dev.sh
```

> **Note:** Ensure you have `tmux` installed on your system before running the script.

## Manual Installation

If you prefer to install the components manually, or if you need to set up a specific environment, please refer to our manual installation guides:

- [Manual Installation](./Manual_Installation.mdx) - Step-by-step guide for the standard manual installation.
- [Manual Installation (Development)](./Manual_Installation_Development.mdx) - Guide for setting up the development environment manually.
